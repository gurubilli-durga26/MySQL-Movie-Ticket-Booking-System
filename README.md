🎬 Movie Ticket Booking System | MySQL Project

📌 About the Project

The Movie Ticket Booking System is a database project built using MySQL. It manages customer details, movie information, theatre details, and ticket bookings through a relational database.

This project demonstrates practical SQL concepts, from basic queries to advanced data analysis.

🎯 Objectives

- Design a relational database for a movie ticket booking system.
- Store and retrieve customer, movie, theatre, and booking information.
- Connect related tables using primary keys and foreign keys.
- Write SQL queries to filter, sort, summarize, and analyze data.
- Practice basic, intermediate, and advanced SQL concepts.

🛠️ Technologies Used

- Database: MySQL
- SQL Editor: MySQL Workbench
- Version Control: Git and GitHub

🗃️ Database Tables

Table| Description
"CUSTOMERS"| Customer information
"MOVIES"| Movie details such as name, genre, and language
"THEATRES"| Theatre information and seating capacity
"BOOKINGS"| Booking details, seats, ticket amount, and payment information

🔗 Table Relationships

- One customer can make multiple bookings.
- One movie can be associated with multiple bookings.
- One theatre can have multiple bookings.

The database uses primary keys (PK) and foreign keys (FK) to identify records and connect related tables.

🚀 How to Run

1. Install MySQL Server and MySQL Workbench.
2. Download or clone this repository.
3. Open MySQL Workbench and connect to your MySQL server.
4. Open the main database SQL script.
5. Execute the script to create and populate the database.
6. Run the simple, medium, and hard query files to explore the SQL examples.
